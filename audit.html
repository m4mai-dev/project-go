🐛 Detail Bug Kritis & Rekomendasi Solusi

Ditemukan dari audit statis kode sumber
BUG #1 [TERSELESAIKAN] - Standardisasi Skema Tabel Kategori category_controller.go

Seluruh query telah disatukan secara presisi menggunakan tabel category dengan kolom id_category dan category_name sesuai ERD.

Status: Diperbaiki & Lolos Kompilasi.
BUG #2 [TERSELESAIKAN] - Handler Lengkap & Terintegrasi category_controller.go

Fungsi CategoryHandler telah mengarahkan semua metode HTTP (GET list, GET by ID, POST create, PUT update, DELETE) secara rapi dan modular.

Status: Diperbaiki & Mendukung fleksibilitas route /category dan /api/category.
BUG #3 - Stok Unit Terkunci Permanen rental_controllers.go

Saat sewa dibuat, status unit di item_instances diubah menjadi 'rented'. Namun saat transaksi selesai (pengembalian barang via UpdateRental), status unit tidak pernah diubah kembali menjadi 'available'.

Solusi Cepat: Tambahkan query UPDATE item_instances SET status = 'available' WHERE id = ? saat rental status menjadi completed/returned.
BUG #4 - Risiko Double Booking Unit Fisik rental_service.go

Fungsi CreateRental tidak memvalidasi apakah unit barang (id_unit) saat ini sedang berstatus 'available' sebelum mengeksekusi insert sewa baru.

Solusi Cepat: Cek status unit di database terlebih dahulu, jika bukan 'available', tolak dengan status HTTP 400 Bad Request.

🚀 Urutan Rencana Eksekusi Fitur per Fitur

  1. Fitur 1 (Kategori): Bersihkan inkonsistensi query SQL dan selesaikan CategoryHandler.
  2. Fitur 2 (Master Produk): Buka akses GET publik dan perbaiki penamaan kolom primary key.
  3. Fitur 3 (Unit Fisik): Sinkronisasi nomor aset dan endpoint filter ketersediaan.
  4. Fitur 4 (Rental Engine): Pasang proteksi *double booking*, sinkronisasi pengembalian unit, dan kalkulasi denda otomatis.
  5. Fitur 5 (Pembayaran): Integrasikan perubahan status pembayaran dengan status pesanan rental.
  6. Fitur 6 (Laporan & Rekapitulasi): Bangun endpoint rekap omset dan laporan sewa admin.
  7. Fitur 7 (RBAC & Keamanan): Pasang middleware pemisah otorisasi Admin vs Pengguna.
